# RockCoast10Be_v3.0 Pakri

Citation: Swirad, Z. M. 2026. zswirad/RockCoast10Be_v3.0 (v3.0). Zenodo [code]. 

Latest version: 3.0 (2026-07-30)

This code accompanies the manuscript: Swirad et al. "Late Holocene evolution of an isostatically uplifting rock coast of the Baltic Sea in Estonia"

It is a modification of the backward geometric model to explore cosmogenic 10Be concentrations across an active shore platform as a function of cliff retreat and shore platform down-wearing scenarios.

The original code (v1.0) is available as a supplement to the publication:

Swirad, Z. M. et al. 2020. Cosmogenic exposure dating reveals limited long-term variability in erosion of a rocky coastline. Nature Communcations 11: 3804. https://doi.org/10.1038/s41467-020-17611-9

The code was subsequently simplified and shared on GitHub at https://github.com/zswirad/RockCoast10Be (v2.0):

Swirad, Z. M. 2025. zswirad/RockCoast10Be: 2.0 (v2.0). Zenodo [code]. https://doi.org/10.5281/zenodo.15783544

Version 3.0 of the code is set-up for the Baltic Sea conditions in Pakri. Specific modifications include:
- relative sea level fall
- no tides
- water denisty rho = 1.01 g/cm3
- assumption of steady-state shore platform down-wearing

Files needed to run the code (geomagnetic scalar, relative sea level time series, topography and measured concentrations) are attached.
